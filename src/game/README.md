# テリにゃん — パズルエンジン

盤面ロジックは全部このフォルダです。UI は `src/components/game/`。

| ファイル | 役割 |
|---|---|
| `types.ts` | 盤面・手・レベルの型 |
| `rng.ts` | シード付き乱数（同じレベルは毎回同じ盤） |
| `rules.ts` | 接触判定、置けないマス、正解セル |
| `solver.ts` | 解の個数（一意性チェック） |
| `generator.ts` | 配置 → なわばり成長 → 一意になるまで再試行 |
| `levels.ts` | レベル1–200の難易度カーブと今日の一問 |
| `storage.ts` | localStorage の進行状況 |
| `audio.ts` | 短い効果音 |

## ルール

1. 各色のなわばりに猫はちょうど1匹
2. 各行・各列に猫はちょうど1匹
3. 猫同士は周囲8マスで隣接できない

`generator.ts` が解を先に置き、そこから領域を育て、`solver.ts` で解が1つだけか確認します。
